# Pages

Business pages should be moved here as `App.tsx` continues to shrink.

Stitch and Figma changes should target these page modules after the shared design boundaries are stable:

- `repair/`
- `customers/`
- `warehouse/`
- `finance/`
- `settings/`

Until a page is moved, keep generated Stitch code in `docs/stitch/exports/` and manually adapt only the needed pieces into project components or the current local page section.
